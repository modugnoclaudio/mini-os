mini-os

Un sistema operativo didattico per x86 a 32 bit, in esecuzione nel tuo browser.

Avvio del PC simulato…

Scrivi direttamente sulla tastiera: i tasti vanno al PC simulato. La tastiera è in layout americano: lettere, numeri, - e . coincidono con quella italiana, gli altri simboli no.

Cosa provare

ComandoCosa fa
helpElenca i comandi della shell.
lsElenca i file del filesystem in RAM.
cat leggimi.txtMostra il contenuto di un file.
run helloEsegue un programma in modalità utente.
run contaUn programma che conta, dormendo tra un passo e l'altro.
run invasoreProva a scrivere nella memoria del kernel: il kernel lo ferma e prosegue.
run cicloNon termina mai: fermalo con Ctrl+C.
scrivi nota.txt ciaoCrea un file; poi cat nota.txt e rm nota.txt.
psElenca i processi.

Cosa c'è sotto

La pagina carica v86, un emulatore di PC scritto in JavaScript e WebAssembly. Dentro quel PC simulato gira lo stesso kernel che si avvia con QEMU: avvio Multiboot, interrupt, memoria virtuale con paginazione, processi con scheduler round-robin, programmi in modalità utente che parlano con il kernel tramite syscall, un filesystem in RAM e questa shell.

I file creati vivono solo in memoria: si perdono con «Riavvia» o ricaricando la pagina.
